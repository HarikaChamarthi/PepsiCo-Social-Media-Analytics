# PepsiCo Social Media Analytics

## Project Overview

This project focuses on analyzing PepsiCo's social media marketing performance using Microsoft Excel. The objective was to transform raw social media data into meaningful business insights by performing data cleaning, data analysis, dashboard creation, and visualization.

The project demonstrates practical Excel skills used in marketing analytics to evaluate customer engagement, campaign effectiveness, platform performance, and follower growth.

---

## Project Objectives

- Clean and prepare raw social media data.
- Analyze engagement across different social media platforms.
- Evaluate campaign performance.
- Study follower growth trends.
- Build an interactive Excel dashboard.
- Generate business insights and recommendations.
